# Checkpoint 02 - Vinheria Agnello

Sistema básico para cadastro e análise de vinhos da Vinheria Agnello. O usuário informa nome, tipo, safra e quantidade em estoque por meio de prompt(), recebe avisos com alert() e visualiza os detalhes no console.log().

## Estrutura do Projeto
* `index.html` – página principal com apresentação do projeto
* `src/css/style.css` – estilos da página e identidade visual
* `src/js/script.js` – código JavaScript do sistema
* `src/pages/` – páginas de história, produtos, equipe e contato
* `src/assets/imgs/` – imagens do site

## Minhas Contribuições

* **Lógica com Repetições:** Implementação de estruturas `while` para validação de dados e repetição do menu.
* **Controle de Fluxo:** Uso de laços `for` para processar e exibir as informações no console.
